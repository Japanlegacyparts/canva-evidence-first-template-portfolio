# Canva Creator portfolio package

Import the SVG files into Canva and reconstruct each as an editable template after the account is accepted into the Template Creator program. Use the PNG files as portfolio previews and visual readback references.

Do not submit automatically. Canva currently requires Creator application acceptance and reviews every submission. Canva also states that obvious AI-generated content or content that cannot be considered wholly yours can be rejected. The owner must review/edit the final in-Canva designs and confirm originality before submission.
