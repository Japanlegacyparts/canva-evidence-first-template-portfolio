# Evidence-First Parts Research Template Portfolio

A coherent six-template visual system for parts researchers, catalog teams, repair businesses, and technical support workflows.

## Included formats

- Square decision card, 1080 x 1080
- Vertical checklist story, 1080 x 1920
- Source authority presentation slide, 1920 x 1080
- A4 evidence decision worksheet, 2480 x 3508
- Carousel cover, 1080 x 1080
- Carousel decision slide, 1080 x 1080

Every asset is provided as editable SVG plus a rendered PNG preview. The system uses only original vector shapes, typography, and layout; there are no external stock assets.
